# 总体架构

## 一、架构分层

```
┌─────────────────────────────────────────────────────────────┐
│                      应用层 (WebUI)                          │
│   网页和控制端 · TypeScript 静态构建 · 黑白圆角设计           │
│   hash 路由:总览 / 设备 / 事件 / 设置                        │
└──────────────────────────┬──────────────────────────────────┘
                           │ REST /api/*
┌──────────────────────────▼──────────────────────────────────┐
│                  服务层 (Server 网关)                        │
│   · 负责管理网页和内核桥接的服务                              │
│   · REST API + WebUI 静态托管 + MQTT 桥接                    │
│   · Home Assistant 集成(MQTT Discovery)                      │
│   · JSON 快照持久化 + Webhook 告警推送                        │
│   · HA 双向桥:全屋实体同步 + 服务调用 + 场景(全屋接管)         │
└──────────────────────────┬──────────────────────────────────┘
                           │ 函数调用 / 消息总线
┌──────────────────────────▼──────────────────────────────────┐
│               核心层 (Core + PlugsCores)                     │
│   Core        负责协调总体:模块总线 / 注册表 / 生命周期        │
│   NetLinker   网络设备连接程序        NetScanear  网络设备发现 │
│   SideAgent   边缘AI模型              HandModel   模块控制    │
│   VEScaner    视频设备发现            YololookUP  视频审计     │
│   SelflookUP  自我审计                ATOGrowUP   成长变异     │
│   AUTOTIME    定时和节律控制                                 │
└──────────────────────────┬──────────────────────────────────┘
                           │ MQTT / TCP / RTSP / ONVIF
┌──────────────────────────▼──────────────────────────────────┐
│               感知层 (家庭设备)                              │
│   门磁 · 人体传感器 · 门锁 · 摄像头 · 温湿度 · 灯 · 空调 ·      │
│   窗帘 · 开关插座 · 风扇 · 报警器(经 HA 全屋接管)             │
│   (原生 MQTT 设备 / 私有协议设备经 SideAgent 桥接)            │
└─────────────────────────────────────────────────────────────┘
```

## 二、技术选型

| 层 | 技术 | 理由 |
| --- | --- | --- |
| 内核/服务 | Rust 2021 + tokio + axum | 静态编译、内存安全、高并发异步 |
| 设备协议 | MQTT(rumqttc) | 轻量、发布订阅、HA 原生支持 |
| 序列化 | serde / serde_json | 静态类型、编译期检查 |
| 前端 | TypeScript + Vite | 严格模式、纯静态产物 |
| 前端风格 | 原生 CSS 设计系统 | 黑白简约、圆角胶囊、零框架 |
| 日志 | tracing / tracing-subscriber | 结构化、级别过滤 |
| 配置 | TOML + serde default | 缺省即用、可覆盖 |
| 调度 | 自研类 Cron + 节律曲线 | 零依赖、贴合安防语义 |
| 持久化 | JSON 快照(纯 std) | 事件/审计/画像重启恢复 |
| 推送 | 零依赖 Webhook(HTTP/1.1) | alert 事件外发(HA/手机) |

## 三、数据流

### 3.1 设备事件流
```
设备 --MQTT--> Server::mqtt --> NetLinker(心跳/建档)
                              --> 事件日志(EventLog)
                              --> ATOGrowUP(行为画像)
                              --> Core 消息总线(广播)
```

### 3.2 安防告警流
```
NetScanear(周期扫描) --> 白名单对比 --> 陌生设备 --> 事件(alert)
YololookUP(抓帧) --> SideAgent(YOLO) --> 审计事件 --> 事件(alert)
ATOGrowUP(画像) --> 异常活跃识别 --> 建议 --> 事件(alert)
SelflookUP(健康自检) --> 在线率异常 --> 事件(warn)
```

### 3.3 控制流
```
WebUI --> POST /api/* --> 各模块 --> 审计日志(SelflookUP) --> MQTT 命令下发
```

│   ├── NetScanear/           # 网络设备发现程序
