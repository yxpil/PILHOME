# 扩展指南

## 一、接入新设备类型

1. `PlugsCores/NetLinker/src/device.rs` 的 `DeviceKind` 增加枚举项;
2. `Server/src/ha/discovery.rs` 增加平台映射与 payload 约定;
3. 设备按 `pilhome/<id>/event` 上报 `{"key":"contact","value":"open"}` 即自动建档;
4. 需要私有协议时,实现 `SideAgent` 或 `NetLinker` 的适配层,把报文转成统一事件。

## 三、新增定时动作

`AUTOTIME` 规则命中后目前写入事件总线;如需触发真实动作:

1. 在 `Server/src/tasks.rs` 的 cron 检查循环中匹配 `rule.action`;
2. 分发到具体执行器(如 MQTT 命令通道 `pilhome/<id>/command`);
3. 例如 action=`arm` → 发布 `pilhome/gateway/command` = `arm`(HA 联动)。

## 四、新增 REST 端点

1. `Server/src/api/` 下新建 `xxx.rs`,handler 签名 `(State<Arc<AppState>>, Json<Req>) -> Json<Value>`;
2. `api/mod.rs` 声明模块并注册路由;
3. WebUI `api.ts` 加对应类型与方法,页面调用。

## 五、新增周期任务

在 `Server/src/tasks.rs` 的 `spawn_periodic` 中仿照现有任务添加:

```rust
{
    let state = state.clone();
    let interval = cfg.tasks.xxx_interval_secs.max(60);
    tokio::spawn(async move {
        let mut interval = tokio::time::interval(Duration::from_secs(interval));
        loop {
            interval.tick().await;
            // 任务逻辑...
        }
    });
}
```

## 六、接入更多 Home Assistant 平台

在 `discovery.rs::payload_for` 中按 HA 规范扩展:
- `binary_sensor` / `sensor` / `lock` / `switch` / `camera`;
- 增加 `json_attributes_topic` 上报附加属性;
- 增加 `availability_topic` 做在线感知(已内置)。

## 七、数据持久化扩展

`Server/src/persistence.rs` 的 `snapshot()` 中追加快照文件即可:
- 规则种群(ATOGrowUP 变异结果);
- 定时规则表;
- 白名单。

## 八、代码规范

- Rust:模块内 `src/` 按职责分文件,`cargo fmt` + `cargo clippy` 通过;
- TS:`tsc --noEmit` 严格模式零错误,`noUnusedLocals` 开启;
- UI:一律使用 `style.css` 设计系统变量,不引入新色值;
- 提交前:`cargo test --workspace` + `npm run build` 全绿。
