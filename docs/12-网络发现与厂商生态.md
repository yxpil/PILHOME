# 网络发现、WOL 唤醒、厂商生态、Token 鉴权与数据存储

## 一、局域网设备发现(自动发现 / 自动分析)

启动即自动执行一轮全自动发现,之后可手动触发:

| 手段 | 说明 |
| --- | --- |
| TCP 端口探测 | 并发扫描 22/80/443/554/1883/5353/8123/9100 |
| ARP 表查询 | `arp -a` 解析,补全 IP ↔ MAC |
| mDNS 零配置发现 | 组播查询 `_hap/_miio/_easylink/_midea/...`,发现智能设备 |
| 端口指纹分析 | 554→摄像头、8123→HA、9100→打印机… |
| MAC OUI 厂商识别 | 小米/华为/美的/海尔/苹果/TP-Link 前缀表 |

全部结果自动入库(带 `ports/fingerprint/confidence/mac/vendor` 属性),
陌生设备触发 alert 级事件。

```bash
curl -X POST localhost:8080/api/discover   # 手动触发一轮发现
curl localhost:8080/api/arp                # ARP 表
curl localhost:8080/api/vendors            # 厂商设备即时发现
```

## 二、WOL 计算机唤醒

标准魔法包(6×0xFF + MAC×16,UDP 广播 9 端口):

```bash
# 直接给 MAC
curl -X POST localhost:8080/api/wol -d '{"mac":"aa:bb:cc:dd:ee:ff"}'
# 按设备 ID(自动读台账 attrs.mac)
curl -X POST localhost:8080/api/wol -d '{"device_id":"net_192.168.1.105"}'
```

设备页:带 MAC 属性的设备显示「唤醒」按钮;顶部可手动输入 MAC 唤醒。

## 三、厂商生态接入(小米/华为/美的/海尔/苹果)

**自动发现(真实可用,零密钥)**:mDNS 服务类型识别——
`_hap`→苹果、`_miio`→小米、`_easylink`→华为、`_midea`→美的、`_hiaircon`→海尔。

**云 SDK 适配器(接口预留)**:`Server/src/vendor.rs` 的 `VendorAdapter` trait
(discover/control),填入厂商开发者密钥即可启用米家云 / Hilink / 美居 / 智家 / HomeKit,
网关代码无需改动。

## 四、API Token 鉴权(开放接入)

```bash
# 1) 签发令牌(默认鉴权关闭,启用后本接口仍放行,操作留痕)
curl -X POST localhost:8080/api/token
# {"ok":true,"token":"<64位hex>",...}

# 2) 启用鉴权:config.toml 设 auth_enabled = true(可预置 api_tokens)

# 3) 外部系统带令牌访问
curl -H "Authorization: Bearer <token>" localhost:8080/api/status
```

放行列表:静态页面、`/api/token`、`/api/ws`。吊销:`POST /api/token/revoke`。

## 五、数据存储:SQLite + MySQL + Excel

| 层 | 说明 |
| --- | --- |
| SQLite | `data/pilhome.db`,事件每 10s 增量落库,重启不丢 |
| MySQL | `config.toml` 配 `mysql_url`,自动建表 + 增量同步(失败降级日志) |
| Excel | `GET /api/export/events?format=xlsx` 标准 .xlsx(OOXML) |
| CSV | `?format=csv` UTF-8 BOM,Excel 双击即开 |

```toml
mysql_url = "mysql://user:pass@192.168.1.10:3306/pilhome"
```
