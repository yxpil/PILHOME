# 部署指南

## 一、环境要求

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Rust | ≥1.75 | 编译全部内核与网关 |
| Node.js | ≥20 | 构建 WebUI |
| Mosquitto(可选) | 任意 | MQTT broker(HA 内置亦可) |
| Home Assistant(可选) | 任意 | 联动平台 |

## 二、构建

```powershell
# 1) 构建 WebUI(tsc 严格检查 + vite 打包)
cd WebUI
npm install
npm run build        # 产物在 WebUI/dist

# 2) 构建并测试 Rust 工作区
cd ..
cargo test --workspace
cargo build --release
```

## 三、配置(`config.toml`)

```toml
# 网关监听地址
listen = "127.0.0.1:8080"
# WebUI 静态目录
webui_dir = "../WebUI/dist"
# 数据目录
data_dir = "data"
# 设备离线判定阈值(秒)
offline_after_secs = 120
# 事件缓冲条数
event_capacity = 4096

[mqtt]
host = "127.0.0.1:1883"
client_id = "pilhome-gateway-1"
topic_prefix = "pilhome"

[ha]
discovery = true
discovery_prefix = "homeassistant"
# 全屋接管:HA WebSocket 地址 + 长效令牌(空 = 不启用)
ws_url = "ws://127.0.0.1:8123/api/websocket"
token = "eyJhbGciOiJIUzI1NiIs..."
sync_interval_secs = 60

[scan]
prefix = "192.168.1"          # 按实际网段修改
ports = [22, 80, 443, 445, 3389, 8123, 1883, 554]
timeout_ms = 300
concurrency = 32

[probe]
prefix = "192.168.1"
rtsp_port = 554
onvif_port = 8000

# 告警 Webhook(空 = 关闭;仅 http)
webhook_url = "http://127.0.0.1:3000/hooks/pilhome"
# 数据快照间隔(秒)
snapshot_interval_secs = 300

[tasks]
scan_interval_secs = 600
cron_tick_secs = 30
evolve_interval_secs = 3600
```

## 四、运行

```powershell
# 方式一:默认配置(无需 config.toml)
cargo run -p pilhome-server

# 方式二:指定配置文件
cargo run -p pilhome-server -- config.toml

# 方式三:Release 二进制
.\target\release\pilhome-server.exe config.toml
```

## 五、验证

| 检查 | 命令/地址 |
| --- | --- |
| WebUI | http://127.0.0.1:8080 |
| 系统总览 | `GET /api/status` |
| 设备台账 | `GET /api/devices` |
| 触发扫描 | `POST /api/scan/run` |
| 设备模拟上报 | `mosquitto_pub -t pilhome/front_door/event -m '{"key":"contact","value":"open"}'` |
| 手势推理 | `POST /api/gesture` body `{"features":[0.05,0.06,0.04,0.05,0.05,0.06,0.05,0.04]}` |
| 规则进化 | `POST /api/evolve/seed` → `POST /api/evolve/tick` |
| 健康自检 | `GET /api/health` |
| 数据恢复 | 重启后检查 `data/events.json` 已加载 |
| 全屋接管 | 配置 `[ha] ws_url+token` 后重启,`GET /api/ha/entities` 应返回实体列表 |
| 一键布防 | `POST /api/ha/scenes` body `{"scene":"arm"}` |
| 添加定时规则 | `POST /api/schedules` body `{"name":"夜间布防","action":"arm","expr":"0 23 * * *"}` |

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| WebUI 404 | 确认 `webui_dir` 指向已构建的 `WebUI/dist` |
| MQTT 连不上 | 确认 broker 地址与账号;HA 场景用其 Mosquitto |
| 扫描全空 | 确认 `[scan] prefix` 与网关实际网段一致 |
| 端口被占用 | 修改 `listen` 或用 `netstat -ano` 排查 |
| 设备不上线 | 检查上报主题格式 `pilhome/<id>/event` 与 JSON 合法性 |
